\section{Environnement technique}

L’environnement technique du projet repose sur les éléments suivants :

\textbf{Langages et Frameworks} :
\begin{itemize}
  \item JavaScript / React pour l’interface web
  \item HTML / CSS / Tailwind / DaisyUI pour la structuration visuelle
  \item Python / FastAPI pour l’API de l’application
  \item MongoDB pour la base de données
\end{itemize}

\textbf{Outils de développement} :
\begin{itemize}
  \item Visual Studio Code (éditeur de code)
  \item GitHub pour le versionning
  \item SDK OVH pour l’intégration avec le cloud provider
\end{itemize}

\textbf{Sécurité / Sanitation} :
\begin{itemize}
  \item Utilisation de bibliothèques sécurisées pour le traitement des données
\end{itemize}

\textbf{Déploiement} :
\begin{itemize}
  \item Hébergement via OVH pour les services web, stockage, messagerie interne et cache
  \item Utilisation de services comme Redis pour la messagerie interne et le cache
  \item Utilisation de services de type bucket S3 pour le stockage de fichiers
  \item Utilisation de services Pub/Sub pour la communication interne à l’application
\end{itemize}
